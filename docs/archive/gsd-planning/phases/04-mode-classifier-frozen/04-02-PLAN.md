### PATH-injection stub CLI pattern (adapted from 04-PATTERNS.md recommendation, §tests/classifier-simulation.sh)

```bash
# Build stub claude shim that echoes canned JSON
mkdir -p "$TEST_DIR/bin"
cat > "$TEST_DIR/bin/claude" <<'STUB'
#!/usr/bin/env bash
# Stub: print whatever canned JSON the test placed in $CLASSIFIER_STUB_FILE.
# Real claude CLI reads prompt from stdin and writes JSON to stdout — this stub matches.
if [[ -n "${CLASSIFIER_STUB_EXIT:-}" ]]; then
  exit "$CLASSIFIER_STUB_EXIT"
fi
if [[ -z "${CLASSIFIER_STUB_FILE:-}" || ! -f "${CLASSIFIER_STUB_FILE:-}" ]]; then
  echo "STUB ERROR: CLASSIFIER_STUB_FILE not set or file missing" >&2
  exit 99
fi
cat "$CLASSIFIER_STUB_FILE"
# Consume stdin so piped prompt doesn't break downstream
cat > /dev/null
STUB
chmod +x "$TEST_DIR/bin/claude"
```

Stub echoes the canned JSON; classifier.sh re-validates + re-emits the canonical schema.

       # Stub claude CLI (PATH-injected). Echoes whatever canned JSON the test
