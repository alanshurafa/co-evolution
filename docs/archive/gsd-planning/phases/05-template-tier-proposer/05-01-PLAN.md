### Env var contract (caller-sets-before-invocation, D-02 + D-03)

```bash
# Required inputs (missing → die exit 1)
export PEL_EVAL_REPORT=/abs/path/to/eval-failure.json     # readable file within REPO_ROOT
export PEL_TEMPLATE_PATH=skills/dev-review/templates/bounce-protocol.md  # .md under templates prefix
export PEL_FLAVOR=bug-catcher                             # ∈ {bug-catcher, faster-converger, blind-spot-surfacer, general}

# Optional overrides
export PROPOSER_MODEL=claude-opus-4-7                     # default; validated against ^[a-zA-Z0-9_.-]+$

# Invocation — $1 is an OPTIONAL free-form task hint. Empty string allowed per D-04.
bash lab/pel/proposer/template/proposer.sh "focus mutation on the bounce pass"
# Or with no hint:
bash lab/pel/proposer/template/proposer.sh ""
```

### Output contract (stdout, unified diff per D-08)

Stdout carries a single unified diff with `---` / `+++` / `@@` headers, exactly one file
target, applyable via `git apply --check` against REPO_ROOT. All diagnostics (model
invocation, validation failures) route to stderr.

Example diff shape the adapter captures from Opus:

```diff
--- a/skills/dev-review/templates/bounce-protocol.md
+++ b/skills/dev-review/templates/bounce-protocol.md
@@ -10,7 +10,9 @@
 Convergence:
 - If there are zero [CONTESTED] and zero [CLARIFY] notes remaining, the plan has converged. Focus on polish only.
-- If this is the final pass, you MUST resolve every remaining note and MUST NOT introduce new unresolved notes.
+- If this is the final pass, you MUST resolve every remaining note and MUST NOT introduce new unresolved notes.
+- When reviewing, actively search for edge cases the original task description did not enumerate. A single missed edge case is worth more than three ratified certainties.
```

### Exit codes (D-07 fail-fast, recommended taxonomy per CONTEXT §Claude's Discretion)

- `0` — success (diff emitted to stdout)
- `1` — input validation failure (missing/unreadable env var file, invalid PEL_FLAVOR, invalid PROPOSER_MODEL, path traversal/out-of-prefix PEL_TEMPLATE_PATH)
- `2` — claude CLI missing / auth failure / Opus call non-zero / empty response
- `3` — malformed diff (not applyable via `git apply --check`) — D-10
- `4` — single-file constraint violation (diff touches >1 file OR non-template file) — D-09

### Post-LLM validation gauntlet (runs in proposer.sh AFTER adapter.sh returns)

Every successful diff from the adapter passes through two checks BEFORE being
emitted to stdout:

1. **D-09 single-file + path-prefix check.** Parse `---`/`+++` headers from the
   diff text. Count unique file targets. If ≠ 1 → die exit 4. Extract the single
   target path. If it does not start with `skills/dev-review/templates/` or
   `tests/fixtures/templates/` (the Plan 02 hermetic test prefix) → die exit 4.
   Grep pattern: `^(---|\+\+\+) [ab]/`.

2. **D-10 `git apply --check` dry-run.** `printf "%s" "$diff" | git apply --check -`
   must exit 0. If not, die exit 3 with the captured stderr dumped for debugging.

Only diffs surviving BOTH checks are emitted to stdout.

### Path sandboxing (T-05-05 mitigation)

Before reading any env-var-provided path, proposer.sh resolves it via
`realpath -m --relative-base="$REPO_ROOT"` (GNU realpath on Linux/Git Bash;
falls back to `python3 -c "import os; print(os.path.realpath(...))"` if
`realpath` is absent). A resolved path that begins with `..` or `/` (absolute
outside REPO_ROOT) is rejected. Both PEL_EVAL_REPORT and PEL_TEMPLATE_PATH go
through this gate before the first `cat` or `read` operation.

### D-05 self-containment invariant

Zero `source` / `.` statements in `lab/pel/proposer/template/**` resolve outside
that directory (same posture as Phase 4's D-05). The ONLY sibling source is
`proposer.sh`'s `source "$SCRIPT_DIR/adapter.sh"`. No reach into
`lib/co-evolution.sh`, `lab/pel/classifier/**`, or runner internals.
