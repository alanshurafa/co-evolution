| pr-emitter.sh → gh (subprocess) | argv-array pass (no shell-eval); body passed via `--body-file` to avoid argv-length + metachar hazards |
| pr-emitter.sh → .co-evolve-cache/ filesystem | Cache files written with deterministic hash-named keys; read-back via jq (no eval) |
