# Co-Evolution — v1.3 Consolidated Audit (2026-06-10)

**Scope:** Full toolkit — runners, shared library, eval harness, PEL lab, tests,
docs — audited across five dimensions: prior-findings reconciliation,
correctness/reliability, security, eval/measurement, architecture/docs.
**Method:** Three parallel research agents + direct spot-verification of every
load-bearing claim; baseline test execution on macOS (first time the suite has
run on a Mac).
**Drives:** Milestone v1.3. Goal ordering: reliability → measurement → adoption
→ simplification, plus two requirements added during planning review:
cross-platform (Mac + PC) operation, and post-bounce human observability.

## 3. Eval / measurement findings

The product's core claim — *a bounced document is better than its input* — is
unmeasured:

- `evals/BOUNCE-RUBRIC.md` is design-only; `evals/score-bounce.sh` does not exist.
- Bounce runs write **no state.json** (the dev-review pipeline does; the
  document bouncer does not).
- Convergence is forced: the final-pass prompt orders all markers removed, so
  "0 markers at end" proves nothing. Marker removal by **section deletion** is
  undetected.
- The agents self-review; no independent or blind judgment exists anywhere.
- "14 eval cases" in older docs = 14 test *tiers* over 9 cases; **0** cover the
  document bouncer.

v1.3 Phases 3–5 close this: instrumentation → deterministic scorer + marker
ledger → blind A/B judge + human report + calibration. Self-review is demoted
from verdict to input; evaluation becomes a 3-layer gate (deterministic / LLM
judge / human sampling).
