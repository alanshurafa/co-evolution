### PEL_* env var contract (caller-sets-before-invocation)

```bash
# Inputs to classifier.sh
export PEL_BOUNCE_STEP=compose          # ∈ {compose, bounce, execute, verify, unknown}; default: unknown
export PEL_PHASE_TYPE=scoping           # ∈ {scoping, implementation, verification, unknown}; default: unknown
export PEL_FLAVOR_OVERRIDE=bug-catcher  # (optional) ∈ {bug-catcher, faster-converger, blind-spot-surfacer, general}; unset = no override
export CLASSIFIER_MODEL=claude-haiku-4-5-20251001  # default per D-06; override for debugging

bash lab/pel/classifier/classifier.sh "the task string as a single argv slot"
```

### Output contract (stdout, single JSON object per D-08)

```json
{
  "flavor": "bug-catcher",
  "rationale": "one-to-three-sentence explanation of why this flavor",
  "override": false,
  "model": "claude-haiku-4-5-20251001",
  "inputs": {
    "task": "the task string",
    "bounce_step": "compose",
    "phase_type": "scoping"
  }
}
```

On override path (`PEL_FLAVOR_OVERRIDE` set and valid), `flavor` = override value, `rationale` = `"user override via PEL_FLAVOR_OVERRIDE"`, `override` = `true`, Haiku is NOT invoked.

### Exit codes (D-07 fail-fast)

- `0` — success (JSON emitted)
- `1` — input validation failure (invalid PEL_FLAVOR_OVERRIDE, invalid CLASSIFIER_MODEL, missing task arg)
- `2` — Haiku unreachable / claude CLI missing / auth failure / rate-limit
- `3` — malformed Haiku response (non-JSON, missing fields, invalid flavor value)

**Haiku invocation shape (mirror `invoke_claude` lib/co-evolution.sh:336-370 — drop `|| true` per D-07):**
```bash
invoke_haiku() {
  local prompt_file="$1" output_file="$2" stderr_file="$3"
  local model="${CLASSIFIER_MODEL:-claude-haiku-4-5-20251001}"
  local -a tool_flags=(--disallowedTools "Edit,Write,Bash,Glob,Grep,WebSearch,WebFetch")
  local -a cmd
  if [[ -n "${WSL_DISTRO_NAME:-}" ]] && command -v cmd.exe >/dev/null 2>&1; then
    cmd=(cmd.exe /c claude -p --output-format text --model "$model" "${tool_flags[@]}")
  else
    cmd=(claude -p --output-format text --model "$model" "${tool_flags[@]}")
  fi
  "${cmd[@]}" < "$prompt_file" > "$output_file" 2>"$stderr_file"
  # NO `|| true` — D-07 fail-fast. Caller inspects exit code.
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv→classifier | `$1` (task string) is untrusted user input, passed to Haiku prompt via placeholder substitution |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Argv injection via `$TASK` passed to Haiku prompt | mitigate | Task string is substituted into prompt ONLY via bash parameter expansion `${template//\{TASK\}/$TASK}` in `compose_prompt()` (Task 2 action step 3) — never concatenated into a shell command, never `eval`'d. Task 3 acceptance: `override_json=$(... 2>/dev/null)` + `jq -e` validates stdout is pure JSON.
