## `_run_status` derivation logic

Mirrors `dev-review.sh`'s existing final-exit switch (now at lines 1475-1483, pre-edit lines 1420-1428 — see final-exit preservation proof below):

```bash
if [[ "$EXECUTE_EXIT" -eq 0 && "$VERIFY_EXIT" -eq 0 ]]; then
  _run_status="completed"
elif [[ "$EXECUTE_EXIT" -eq 2 || "$VERIFY_EXIT" -eq 2 ]]; then
  _run_status="partial"
else
  _run_status="failed"
fi
```

Values conform to `evals/RUNNER-CONTRACT.md` §1 (`pending | completed | failed | partial`). `pending` is runner-init-only (Plan 01 seeds it via `init_state_json`); observing `pending` at scorer-read time means the runner aborted before EOF, which maps to `failed` per §1.

## `phases → history` mirror shape

Literal jq transformation (dev-review.sh:1449-1450):

```bash
jq '.history = (.phases | map({phase: .name, status: .status, detail: "", timestamp: .completed_at}))' \
   "$STATE_JSON" > "$_tmp_history"
```

Each `phases[]` entry becomes a `history[]` entry with fields `{phase, status, detail, timestamp}` matching the RUNNER-CONTRACT.md §1 shape. `phase ← .name` (phases-side uses `name`, history-side uses `phase` — the canonical contract field). `status ← .status` (same field name on both sides). `detail ← ""` (empty placeholder; phases doesn't carry a detail field). `timestamp ← .completed_at` (closest semantic analog on the phases-side; scorer's Convergence structural check at score-run.sh:338 reads `.phase` to match `^bounce-[0-9]+$`, not `.timestamp`, so the empty-or-approximate value is non-load-bearing).

Ordering: `.status`, `.completed_at`, `.updated_at` written FIRST; then `phases → history` mirror runs on the resulting state.json. If reversed, the history entries would miss the final-phase completion timestamps that `write_state_phase` appends during per-phase execution.

Failure posture: `command -v jq` guard + mktemp + conditional mv. On jq failure, the temp file is removed and state.json is unchanged — a WARNING is logged via the existing `log` helper (`.history` will read as `[]` on the scorer side, triggering the `// "unknown"` / empty-array fallback rather than crashing).
