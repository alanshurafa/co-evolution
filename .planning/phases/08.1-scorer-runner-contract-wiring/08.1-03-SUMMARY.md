## Task 2 — WR-04 `--run-dir` injection (commit 3242b08)

Added `--run-dir "$fixture/.co-evolution/runs/dev-review-${iteration}"` to the
runner invocation. **Approach A (unconditional injection) chosen.** Rationale:
inspected `evals/tests/fake-runner.sh:47-57` argv loop; it has a default
`*) shift ;;` arm that silently swallows unknown flags. So passing
`--run-dir` to the fake runner is a safe no-op. Approach B (conditional on
`$RUNNER_PATH_ABS == *dev-review.sh`) was the fallback if Tier 2 broke; it
didn't, so A was simpler.

**Path rationale:** fixture-absolute form `"$fixture/.co-evolution/runs/dev-review-${iteration}"`
chosen over relative `".co-evolution/runs/dev-review-${iteration}"` for
diagnostic clarity and resilience against future refactor that might remove
the `cd "$fixture"` in the subshell at line 274. Template matches what
`fake-runner.sh:64` already writes (`.co-evolution/runs/${RUN_ID}`) so both
runners converge on the SAME subtree under the fixture — the newest-run
discovery at run-evals.sh:284-287 works unchanged for both.

**Acceptance:**
- `grep -c -- "--run-dir" evals/run-evals.sh` → 3
- `grep -c "fixture/\.co-evolution/runs/dev-review-\${iteration}" evals/run-evals.sh` → 1
- `grep -c "fixture/.co-evolution/runs" evals/run-evals.sh` → 4 (1 injection + 1 discovery hit + 2 comment refs)
