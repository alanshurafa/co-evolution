## Shared Patterns

### Atomic jq writes (applies to all state.json mutations)
**Source:** `lib/co-evolution.sh::write_state_field` (lines 965-1003) + `write_state_phase` (lines 927-960)
**Apply to:** WR-01 `.status` write, any new field additions in `init_state_json`.
Pattern:
```bash
tmp=$(mktemp)
if jq '...' "$state_path" > "$tmp"; then
  mv "$tmp" "$state_path"
else
  rm -f "$tmp"
  log "WARNING: jq failed in <context>"
fi
```
