<decisions>
## Implementation Decisions

### Contract direction (addresses WR-01, WR-02)

- **D-01:** Write a shared contract doc at `evals/RUNNER-CONTRACT.md` specifying the exact state.json fields and artifact paths both `dev-review.sh` and `score-run.sh` commit to. Both sides conform to the doc rather than one chasing the other.
- **D-02:** WR-01 fix — `dev-review.sh` writes top-level `.status` in state.json. Values: `pending` (init sentinel, written by `init_state_json` at run start), `completed` (all phases green), `partial` (exit-band 2 — some phases failed but run reached end), `failed` (exit-band >= 3 or hard abort). Derived at the end of the run from the phase status array and exit code. [Amended 2026-04-19 post-plan-check: original wording `completed/failed/unknown` was loose; planner + plan-checker identified richer 4-value set gives scorer Robustness dimension a cleaner signal. `unknown` dropped — any non-sentinel unknown state indicates a hard abort, which maps to `failed`.]
- **D-03:** WR-02 fix — `dev-review.sh` writes compose output to `outputs/compose.txt` (not dot-prefixed) and bounce outputs to `outputs/bounce-NN.txt`. Cleanup logic updated so compose output survives the run. If backward-compat is an issue, emit both the old and new path for one minor version with a deprecation log.

### `--autonomous` flag (addresses WR-03)

- **D-04:** Remove `--autonomous` passthrough from `evals/run-evals.sh`. No committed case sets `runner.autonomous: true`, and the feature isn't planned for v1.2. The `run-evals.sh` caller that composes flags should skip this flag entirely. If a future case needs autonomous mode, add it then — not speculatively.

### Run directory convention (addresses WR-04)

- **D-05:** Add a `--run-dir <path>` flag to `dev-review/codex/dev-review.sh`. When unset, runner defaults to existing `$REPO_ROOT/runs/dev-review-<ts>/` (preserves non-eval use). When `evals/run-evals.sh` invokes the runner, it passes `--run-dir "$fixture/.co-evolution/runs/dev-review-<ts>/"`.
- **D-06:** Byte-parity preservation: default behavior (no `--run-dir`) must produce byte-identical state/artifacts vs v1.2. Add a regression check to the test suite.

### Test coverage — root cause fix

- **D-07:** Extend `evals/tests/scorer-verification.sh` with a new tier or scenario: "real-runner smoke test" that runs the actual `dev-review.sh` against at least one fixture with a tiny prompt (hermetic — stub out AI calls). Asserts state.json shape matches the contract doc AND scorer can consume it. This is the regression barrier that would have caught WR-01/02/04.
- **D-08:** The fake-runner contract (`evals/tests/fake-runner.sh`) and real-runner contract (`dev-review.sh`) must be kept in sync by the shared `evals/RUNNER-CONTRACT.md`. Both runners conform to the same doc. A future lint/check step should diff actual state.json keys against the contract.

### Phase 8 invariants carried forward

- **D-09:** Byte-parity for non-`--lab` invocations (SC-5) still holds. Any `dev-review.sh` change must preserve byte-identical output for users not using `--run-dir` or eval flows.
- **D-10:** Frozen-surface classifier (Phase 4) untouched. Frozen allowlist for code-tier proposer (Phase 7) untouched.
- **D-11:** The PR-emitter cache key (Phase 8) currently includes `scripts_hash` over runner + scorer. Contract changes will invalidate existing caches — acceptable, documented in the contract doc.

### Claude's Discretion

- Exact field naming in the contract doc (kebab vs snake, nesting depth) — match existing conventions in state.json.
- Whether to emit both old and new compose.txt paths during a transition period (D-03) — decide based on whether any currently-committed tooling reads the dot-prefixed path; if nothing does, make the jump cleanly.
- Location of the real-runner smoke test (new Tier 4 in scorer-verification.sh vs separate `tests/runner-contract.sh`) — pick whichever keeps the file layout symmetric with existing tiers.
- Whether to rename `run-evals.sh`'s `--autonomous` plumbing code paths (D-04) — if removal leaves dead argument-parsing branches, clean them up in the same commit.

</decisions>
